# CV Лабораторная работа — Шнуренко София

Персональное резюме, сделанное в рамках лабораторной работы по CI/CD и GitHub Pages.

## О проекте

В этой работе собраны мой опыт, навыки и интересные факты обо мне. Всё это реализовано как резюме.

В качестве нестандартного элемента реализовано красивое оформление в коллажном стиле. Также добавлены всякие интерактивные элементы (буквы разбегаются при наведении на текст мышкой, кнопка с фактами, при нажатии которой выбрасываются конфетти и т.д.)
