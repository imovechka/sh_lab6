## Про CV

Сайт оформлен в **винтажном газетном стиле**: тёплая палитра крафтовой бумаги, декоративные шрифты, анимированные буквы в имени. Каждый раздел оформлен по-своему:

- **Шапка** — анимированные разноцветные буквы (шрифт Harlequinade), кнопки копирования контактов
- **Обо мне** — простой текстовый блок
- **Опыт и проекты** — стилизован под кассовый чек с рваными краями и штрихкодом
- **Навыки** — цветные стикеры-наклейки
- **Случайный факт обо мне** — облачко с акварельной текстурой, при нажатии конфетти летят во все стороны

## Стек

- [Vite](https://vitejs.dev/) — dev server + бандлер
- Vanilla JS + HTML + CSS
- ESLint 9 (flat config)
- GitHub Actions — CI + CD

## Локальный запуск

```bash
npm install
npm run dev      # dev server на http://localhost:5173
npm run lint     # проверить код
npm run build    # собрать в dist/
npm run preview  # посмотреть прод-сборку локально
```
